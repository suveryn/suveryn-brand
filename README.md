The chat UI in [suveryn-core](https://github.com/suveryn/suveryn-core) copies the mark, fonts and `tokens/tokens.json` from this repository at a pinned commit, so a change here reaches it when it re-syncs. Colours are OKLCH and written by rules: `tokens/palette.py` holds the palette's rules and writes every value (`--check` verifies the file against them and every contrast pair); see the guidelines, *Colours are written in OKLCH* and *The palette's rules*.

# logo

The sūveryn mark as asset files; when to use each: the guidelines, [*The brand mark*](../guidelines/brand-guidelines.md#the-brand-mark). All rights reserved: [TRADEMARK_POLICY.md](../TRADEMARK_POLICY.md).

- `suveryn-icon.svg`: the icon, single-ink orange.
- `suveryn-logotype-dark-bg.svg`: icon and wordmark, for dark surfaces.
- `suveryn-logotype-light-bg.svg`: icon and wordmark, for light surfaces.
- `favicon.svg`: the icon tuned for browser tabs.
- `apple-touch-icon.png`: the icon on a white tile, 180 px, for phone home screens.
- `icon-192.png`, `icon-512.png`: the same, 192 and 512 px, for a web app manifest.
- `suveryn-github-avatar.png`: the icon on a dark tile, 512 px, for the GitHub organisation.
